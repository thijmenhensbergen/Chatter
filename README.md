# Chatter
A simple chatroom website made as a school project.
Cannot be hosted as I built it wrong but it works completely fine locally. sorry i didnt have experience with this before.

Functions:
Multiple rooms with each allowing users to message in it.
Account System with a username, hashed password and profile picture.
Admin panel that can create, edit or delete rooms and edit or delete users.
Admin users that can delete any message.
Database support.

    
Install Instructions (to run locally)
1. Download the project.
2. Import chatter.sql in your database.
3. In the base repository, run 'node server.js' in the terminal. (you probably need node for this)
4. go to localhost
